앱 빌드 및 설치 가이드

  • 1

    프로젝트 열기 (Open Project)

    Android Studio를 실행하고 File > Open을 선택한 후 저장소 루트 디렉터리(smart-atm-android-app)를 엽니다.

  • 2

    Gradle 동기화 (Sync Project with Gradle Files)

    상단 코끼리 아이콘(Gradle Sync)을 클릭하여 의존성을 내려받습니다. JDK 설정이 Java 17로 지정되어 있는지 확인합니다 (Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK).

  • 3

    스마트폰 USB 디버깅 연결

    시연에 사용할 안드로이드 스마트폰의 설정 > 개발자 옵션 > USB 디버깅을 활성화하고 PC와 연결합니다.

  • 4

    앱 실행 (Run 'app')

    상단 실행 대상 기기를 연결된 스마트폰으로 선택하고 녹색 삼각형 Run(Shift + F10) 버튼을 클릭하면 APK가 컴파일 및 스마트폰에 자동 설치됩니다.

Android Studio 없이 터미널에서 Gradle 래퍼와 adb를 통해 직접 빌드하고 설치할 수 있습니다.

Windows PowerShell 
# 1. 프로젝트 디렉터리로 이동
cd smart-atm-android-app

# 2. 디버그용 APK 빌드
.\gradlew.bat assembleDebug

# 3. 연결된 기기에 APK 직접 설치
adb install -r app/build/outputs/apk/debug/app-debug.apk
macOS / Linux Bash 
# 1. 실행 권한 확인 및 빌드
chmod +x gradlew
./gradlew assembleDebug

# 2. adb 설치
adb install -r app/build/outputs/apk/debug/app-debug.apk

1단계: 서버 주소 & 로그인 설정

전시장 무선망 IP 유동 대응 및 토큰 보관

전시 부스 환경에서는 공유기 재부팅이나 장소 변경으로 서버 IP가 수시로 바뀝니다. 앱을 재빌드하지 않고 화면 상단 우측 [설정 ⚙️] 아이콘을 눌러 즉시 변경할 수 있습니다.

필수 설정 1

서버 URL 및 연결 확인

백엔드 PC의 IP와 포트 번호를 입력합니다.

  • 형식: http://192.168.0.x:8000
  • [연결 확인 (GET /health)] 버튼으로 200 OK 수신 여부 확인
  • 입력 시 SharedPreferences에 자동 영구 저장
필수 설정 2

시연 계정 로그인

토큰 기반 인증으로 안전하게 백엔드와 연동합니다.

  • 아이디: halmeoni (시연 기본 계정)
  • 비밀번호: 설정된 시연 비밀번호 입력
  • 로그인 성공 시 12시간 동안 유지되는 토큰 발급
  • 초록색 ✓ 토큰 보유 중 문구 확인 후 뒤로가기

2단계: 의심 내용 입력 (3가지 방식)

보이스피싱 사전 검사 화면에서는 어르신이나 사용자가 직관적으로 내용을 검사할 수 있도록 3가지 유연한 입력 경로를 제공합니다.

방식 1

문자 앱에서 [공유]

스마트폰 기본 메시지 앱이나 카카오톡에서 의심 문자를 길게 누른 뒤 [공유] > [보이스피싱 사전 검사]를 선택합니다.

  • 앱이 열리며 본문이 자동 채워집니다.
  • 즉시 분석하지 않고 사용자가 눈으로 확인 가능합니다.
방식 2

통화 음성 실시간 받아쓰기

통화 녹음이나 대본 음성을 다른 기기(PC·다른 폰)에서 틀고, 이 폰의 [실시간 받아쓰기] 버튼을 누릅니다. 실제 전화가 연결된 같은 폰에서는 안드로이드가 마이크를 무음으로 막아 받아쓸 수 없습니다 (스피커폰으로 바꿔도 같습니다).

  • 들려주는 목소리가 실시간 글자로 누적됩니다.
  • 상대방이 잠시 말을 멈추어도 자동 재시작 루프 작동
  • 통화 종료 후 [중지] 누르고 오타 직접 수정 가능
방식 3

원클릭 시연 대본 칩

전시 심사 및 빠른 검증을 위해 4가지 표준 시연 칩이 제공됩니다.

  • [보이스피싱 통화 (100점)]
  • [보이스피싱 문자 (100점)]
  • [일반 통화 (0점)]
  • [일반 문자 (0점)]
글자 수 2,000자 제한

서버 백엔드 규격에 따라 분석 본문은 최대 2,000자입니다. 5분 이상의 장시간 통화 시 글자 수 카운터가 표시되며 필요 시 요약 편집 후 검사할 수 있습니다.

3단계: Wi-Fi 2대 스마트폰 Mock 통화 (PRD v2.0)

안드로이드 OS 통화 녹음 제약 극복 및 실시간 통화형 탐지

일반 앱의 통화 녹음이 차단된 안드로이드 10+ 보안 정책에 대응하여, 같은 Wi-Fi 망의 2대 스마트폰(공격자 vs 피해자)이 앱 내부에서 음성 통화를 시뮬레이션하면서 실시간 STT 자막과 위험도 점수를 즉각 모니터링합니다.

역할 A

🚨 스마트폰 A (공격자 모드)

보이스피싱 범죄자 역할을 수행하며 시연 대본을 읽거나 통화를 유도합니다.

  • [방 만들기 (호스트)]: 로컬 IP 및 세션 ID(VP-CALL-001) 자동 생성 및 Wi-Fi 비콘 송출
  • [전화 걸기 (CALL OFFER)]: 상대방 폰으로 통화 요청
  • [원클릭 대본 퀵 전송]: 전시장 소음 환경 대비 100점 대본 즉시 전송 지원
역할 B

🛡️ 스마트폰 B (피해자 모드)

어르신/일반 고객 역할을 수행하며 통화를 수신하고 실시간 경고를 받습니다.

  • [원클릭 방 참여]: 같은 Wi-Fi 내 탐색된 방 리스트에서 바로 참여 (수동 IP 입력도 지원)
  • [전화 수락 (CALL ANSWER)]: 저지연 UDP PCM 음성 통화 즉시 연결
  • [실시간 위험도 모니터링]: SAFE ➔ CAUTION ➔ DANGER 실시간 경고 배너 표출
  • [통화 종료 후 QR 연동]: 통화 종료 시 원클릭으로 ATM 출금 차단 QR 화면(S9)으로 이동
기존 백엔드 API & DB 계약 100% 호환

Mock 통화 기능은 별도 백엔드를 요구하지 않으며, 기존 POST /api/v1/analysis에 STT 텍스트를 전달하는 새로운 실시간 입력 경로로 완벽하게 통합 작동합니다.

4단계: 위험도 분석 및 판정

내용 입력 후 하단의 [검사하기] 버튼을 누르면 백엔드 규칙 엔진(POST /api/v1/analysis)으로 전송되며 3초 이내에 종합 판정 결과를 반환합니다.

등급 (Risk Level) 위험 점수 ATM 조치 (Action) QR 코드 표출 여부
DANGER (위험) 70 ~ 100점 BLOCK (출금 전면 차단) ✅ 표출 (ATM 태깅 필요)
CAUTION (주의) 40 ~ 69점 VERIFY (추가 본인 인증) ✅ 표출 (본인 확인 연동)
SAFE (안전) 0 ~ 39점 ALLOW (정상 거래 승인) ❌ 미표출 (일상 거래 보호 원칙)
결과 화면 하단에는 탐지 근거(예: "기관 사칭 표현 감지", "대포통장 및 범죄 연루 언급", "안전계좌 이체 요구")가 상세 목록으로 명확하게 나열되어 어르신에게 직관적인 경각심을 줍니다.

5단계: ATM 연동 QR 표출 및 출금 차단

라즈베리파이 카메라 인식 극대화 핵심 4대 수칙

전시장 조명 환경과 라즈베리파이 640×480 카메라 렌즈 조건에서 100% 한 번에 인식되도록 아래 하드웨어 제어 로직이 구현되어 있습니다.

수칙 1

화면 밝기 100% 강제 고정

QR 화면 진입 시 스마트폰 밝기를 즉시 최대(1.0)로 끌어올리고, 화면 꺼짐 방지(FLAG_KEEP_SCREEN_ON)를 실행합니다. 화면을 벗어나면 원래 밝기로 복원됩니다.

수칙 2

순수 흑백 고대비 & 70% 폭

테마 색상이나 그라디언트를 일체 배제하고 순수 흰색(#FFFFFF) 바탕에 검은색(#000000) 모듈로 가로 폭 85% 이상 큼직하게 렌더링합니다.

수칙 3

최적 카메라 거리 15~25cm

ATM 기기 전면 카메라와 스마트폰 화면의 거리를 약 한 뼘(15~25cm) 간격으로 비추었을 때 가장 빠르게 초점이 잡힙니다.

수칙 4

경량 JSON 데이터 계약

QR에는 오직 {"session_id": "VP-000012"} 포맷만 담깁니다. 개인정보는 일체 배제되며 ATM이 서버와 직접 통신합니다.

ATM 출금 차단 성공 확인 (S4)

스마트폰의 위험 QR을 ATM 카메라에 비추면, ATM 화면이 경고 빨간색으로 바뀌고 50만원 출금 버튼을 눌러도 현금 배출 서보모터가 작동하지 않고 잠깁니다.

4. 일반 문자용 (대조군) 0점 · SAFE
어머니, 목요일 병원 예약 2시입니다. 처방전 잊지 마세요.

트러블슈팅 & FAQ

?

Q1. "서버에 연결할 수 없습니다" 오류가 발생합니다.

1. 스마트폰과 백엔드 PC가 동일한 Wi-Fi 네트워크(동일 서브넷)에 접속해 있는지 확인하세요.
2. 백엔드 PC의 방화벽(Windows Defender 등)에서 8000번 포트 인바운드가 열려있는지 확인하세요.
3. 앱 우측 상단 ⚙️ 설정에서 http://[백엔드PC의 실제 IP]:8000을 정확히 입력 후 [연결 확인]을 클릭하세요.

?

Q2. 통화 음성인식(STT)이 중간에 자꾸 멈춥니다.
